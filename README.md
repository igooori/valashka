# 🤖 Nevalashka — Commercial Telegram Bot

Коммерческий Telegram-бот под ключ с интеграцией платежных систем (ЮKassa + криптовалюта), системой подписок, интеграцией с Google Sheets в качестве CRM, модерацией анкет и встроенной поддержкой (тикет-системой).

---

## 🛠️ Стек технологий
* Язык: Python
* Telegram Bot API: aiogram
* Базы данных & Хранение: SQLite / SQLAlchemy, Google Sheets API (CRM)
* Платежи: ЮKassa, криптовалютные переводы

---

## 🚀 1. Быстрый старт и настройка окружения

1. Установите Python 3.11+.
2. Создайте виртуальное окружение в корне проекта:
   python -m venv venv
3. Активируйте окружение:
   - Windows: venv\Scripts\activate
   - Linux/macOS: source venv/bin/activate
4. Установите зависимости:
   pip install -r requirements.txt
5. Создайте файл .env (или настройте settings.py) со следующими параметрами:
   - BOT_TOKEN — токен Telegram-бота от @BotFather.
   - ADMIN_ID — Telegram ID администратора (или несколько через запятую).
   - Реквизиты платежных шлюзов.
6. Запустите бота:
   python main.py
   (При успешном старте в консоли появится сообщение о запуске).

## 💳 2. Настройка платежей (ЮKassa)

В текущей версии бот настроен на тестовый режим ЮKassa (реальные деньги не списываются, используются тестовые ключи).

Как переключить на боевой режим:
1. Войдите в личный кабинет ЮKassa и завершите подключение магазина (прохождение проверки, заключение договора).
2. Получите боевые реквизиты:
   - shop_id (идентификатор магазина)
   - secret_key (секретный ключ)
3. Замените тестовые ключи на боевые в настройках проекта (settings.py или .env).
4. Проведите 1–2 тестовых платежа на минимальную сумму, чтобы убедиться, что:
   - Оплата успешно проходит через ЮKassa.
   - Бот корректно выдает доступ к уровням («Путь» / «Сила»).
   - Данные о транзакции автоматически фиксируются в листе Payments в Google Sheets.

## 📊 3. Интеграция с Google Sheets (CRM)

Бот автоматически синхронизируется с общим табличным файлом (NEVALASHKA_bot_CRM), который разделен на несколько листов:

* Users — база пользователей:
  - user_id | registration_date | subscription_end (срок окончания подписки на уровень «Путь»).
* Payments — финансовый учет (ЮKassa + крипта):
  - user_id | payment_id | amount_rub | amount_usdt | currency | system | status | product_type | tariff_period | created_at | subscription_end | type
* Applications — анкеты для доступа к уровню «Сила» и их статус модерации:
  - user_id | q1 | q2 | q3 | q4 | username | created_at | status
* Tickets — обращения пользователей в службу поддержки:
  - ticket_id | user_id | username | status | created_at | message | type

## ⚙️ 4. Логика уровней и функционал

### Уровень «Путь»
1. Пользователь выбирает тариф и производит оплату (через ЮKassa или криптовалюту).
2. После успешного проведения платежа:
   - В базе данных и в Google Sheets обновляется статус и дата окончания подписки (subscription_end).
   - Пользователь получает уведомление: «Вы приняты. Доступ к уровню Путь открыт...».
   - В интерфейсе активируются кнопки [Перейти в Путь] (ссылка на закрытый канал/чат) и [Поддержка].

### Уровень «Сила»
1. Пользователь оплачивает доступ к уровню и заполняет интерактивную анкету из 4 вопросов.
2. Анкета автоматически отправляется в Google-таблицу (Applications) со статусом «на модерации».
3. Администратор рассматривает заявку и выносит решение.

### Система поддержки (Тикеты)
- При нажатии кнопки «Поддержка» бот предлагает описать возникшую проблему.
- Следующее текстовое сообщение пользователя:
  - Создает или обновляет тикет в базе данных.
  - Пересылается администратору в личные сообщения в Telegram.
  - Фиксируется отдельной строкой на листе Tickets в Google Sheets.
- Администратор отвечает пользователю напрямую через личные сообщения.

## 🔧 6. Кастомизация без изменения кода
- Тексты сообщений: настраиваются в файлах модулей (commands.py, payments.py, applications.py, support.py).
- Ссылки на закрытые каналы/чаты: редактируются в функциях выдачи доступа (поиск по ключевым фразам перехода в проекты).
- Тарифы и сроки подписок: задаются в логике формирования кнопок выбора тарифа (payments.py).
